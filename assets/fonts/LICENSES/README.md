# Bundled font licenses

DocMark ships six open-source families. Every family is licensed under the
SIL Open Font License 1.1 (OFL-1.1), except Roboto and Roboto Mono, which are
licensed under the Apache License 2.0.

| Family | Directory | License |
|---|---|---|
| Inter | `assets/fonts/inter/` | OFL-1.1 |
| Roboto | `assets/fonts/roboto/` | Apache-2.0 |
| Roboto Mono | `assets/fonts/roboto_mono/` | Apache-2.0 |
| Montserrat | `assets/fonts/montserrat/` | OFL-1.1 |
| Lora | `assets/fonts/lora/` | OFL-1.1 |
| Merriweather | `assets/fonts/merriweather/` | OFL-1.1 |
| Caveat | `assets/fonts/caveat/` | OFL-1.1 |

T9 drops the real `.ttf` bytes and the per-family `OFL.txt` / `LICENSE` text
into these directories. Until then every face is a placeholder and the
license files for each family live here as the contract.
